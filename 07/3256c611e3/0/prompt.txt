# Plan: Fix Search Highlight Sizing Using transform[3] (Font Size)

## Problem

Current highlight height uses `divRect.height` from `getBoundingClientRect()`, which gives the rendered box height. This may not match the actual text height for different font sizes.

The original `textContent.items[i].transform[3]` (scaleY = font size in PDF points) is **discarded** after TextLayer renders - only HTML spans are stored.

## Solution

Store font size from `transform[3]` before TextLayer renders, then use it to properly size highlights.

## Key Formula

```
highlightHeight = Math.abs(transform[3]) * viewport.scale * (96/72)
```

Where:
- `transform[3]` = font size in PDF points (72 DPI)
- `viewport.scale` = 1.5 (rendering scale)
- `96/72` = DPI conversion (PDF to CSS units)

## Implementation

### File to modify
`packages/web/src/routes/+page.svelte`

### Step 1: Update PageTextData interface (lines 29-34)

Add `fontSizes` array to store font heights per text item:

```typescript
interface PageTextData {
  pageWrapper: HTMLElement;
  viewport: { width: number; height: number; scale: number };
  textDivs: HTMLElement[];
  textContentItemsStr: string[];
  fontSizes: number[];  // NEW: font height in rendered pixels per text item
}
```

### Step 2: Store font sizes when building pagesData (lines 308-328)

After `getTextContent()`, extract and convert font sizes before passing to TextLayer:

```typescript
const textContent = await page.getTextContent();

// Extract font sizes from transform[3], convert to rendered pixels
const PDF_TO_CSS_UNITS = 96 / 72;
const fontSizes = textContent.items.map((item) => {
  if ('transform' in item) {
    return Math.abs(item.transform[3]) * viewport.scale * PDF_TO_CSS_UNITS;
  }
  return 12 * viewport.scale * PDF_TO_CSS_UNITS; // fallback
});

// After TextLayer.render(), store alongside other data:
pagesData.push({
  pageWrapper,
  viewport: { width: viewport.width, height: viewport.height, scale: viewport.scale },
  textDivs: textSpans,
  textContentItemsStr: textSpans.map((s) => s.textContent ?? ''),
  fontSizes  // NEW
});
```

### Step 3: Use stored font size for highlight height (line 142)

Replace `divRect.height` with the pre-calculated font size:

```typescript
// Current:

// New:

highlight.style.height = `${fontSize}px`;
```
